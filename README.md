# DSA

Personal practice repo for Data Structures & Algorithms in C++, following the [DSA Series by Shradha Ma'am](https://www.youtube.com/playlist?list=PLfqMhTWNBTe137I_EPQd34TsgV6IO55pt) (Apna College).

## Structure

Each topic gets its own folder, named after the lecture topic, containing the C++ source for that lecture's practice.

| Folder | Topic | Lecture |
|---|---|---|
| [variable_data_types_operators/](variable_data_types_operators/) | Variables, Data Types & Operators | Lecture 2 |

## Running

Each folder has a `code.cpp`. Compile and run with g++:

```bash
g++ code.cpp -o code
./code
```

A VS Code build task (`C/C++: g++ build active file`) is also set up under `.vscode/tasks.json`.
